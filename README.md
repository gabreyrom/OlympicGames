# Inside the Olympics — 120 Years of Olympic Games

A data analysis project exploring 120 years of Olympic Games history, combining athlete records with country-level socioeconomic indicators to uncover patterns in medal dominance, host-country advantage, female participation, and athlete physiques.

**Authors:** Juan Pablo Harfush, Luis Delfín, Gabriel Reynoso

## Overview

The analysis is organized into five main themes:

1. **World Domination** — which countries/teams have historically dominated the medal tables.
2. **Domination by Sport** — medal concentration across individual summer and winter sports.
3. **Host's Advantage** — whether hosting the Olympics correlates with improved performance, examined per host country/edition.
4. **Female Participants** — the growth of female participation over time, by season and by sport.
5. **Physical Attributes per Discipline** — age, height, weight, and BMI trends for men and women across summer and winter sports.

## Repository Structure

### Notebooks

| Notebook | Description |
|---|---|
| `Inside the Olympics.ipynb` | Main analysis notebook covering all five themes above. |
| `Motivation.ipynb` | Background and motivation for the project's direction. |
| `HistoricOlympicsSummer.ipynb` / `HistoricOlympicsWinterAndHosts.ipynb` / `HistoricOlympicsSummerAndHosts.ipynb` | Historic medal trends and host-country effects for the Summer and Winter Games. |
| `Top3HistoricalSummer.ipynb` / `Top3HistoricalWinter.ipynb` | Top-3 historical medal leaders (Summer/Winter). |

### Data

| File | Description |
|---|---|
| `athlete_events.csv` | 120 years of individual athlete-event records (name, sex, age, height, weight, team, NOC, games, sport, event, medal). |
| `medallero.csv` | Medal table by year and country (Gold/Silver/Bronze). |
| `FPPC_summer.csv` / `FPPC_winter.csv` | Female/male participant counts and female participation percentage (FP) by NOC and year. |
| `ph_fems_summer.csv` / `ph_fems_winter.csv` / `ph_men_summer.csv` / `ph_mens_winter.csv` | Average physical attributes (age, height, weight, BMI) by sport and year, split by sex and season. |
| `GDP.csv` / `Population.csv` / `GINI.csv` / `HDI.csv` / `Education.csv` | Country-level socioeconomic indicators (World Bank / UN sources) used to contextualize national Olympic performance. |

### Other

- `Graphs/` — exported chart images (PNG) generated by the notebooks.
- `Inside the Olympics - final presentation.pptx` — final presentation summarizing the project's findings.

## Getting Started

1. Install dependencies:
   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```
2. Launch Jupyter and open a notebook:
   ```bash
   jupyter notebook "Inside the Olympics.ipynb"
   ```
3. Run cells in order — notebooks read the CSV files directly from the repository root, so no path configuration is needed.
